# 账本界面与统计口径验收

2026-10-30。本次按已确认方案实施：还款本金默认不计入统计；移除重复的收支概览；交易类型筛选提供收入、支出、转账、退款（多选，无选择代表全部交易）。原有还款和余额调整记录仍会显示在未筛选的明细里。

## 页面与计算规则

- 明细、统计、预算共用月份选择与月份状态。明细顶部头像进入“我的”，三项收支金额分别进入支出、收入、结余统计。每次从金额入口进入统计时回到顶部、清除统计范围及成员/分类筛选。
- 预算独立设置，入口位于明细预算区域和“我的”。一级分类使用金额汇总二级分类，退款抵减原分类。每项展示剩余或超支金额，未设置预算的分类有明确状态。
- 当月日均支出：当月支出 ÷ 已过天数（含今天）；历史月份除以全月天数，未来月份显示“—”。
- 预算日均剩余：（明细预算显示额度 − 所选分类当月支出）÷ 剩余天数（含今天）。历史月份显示“已结束”；未来月份除以全月天数；未设置预算时显示“未设置”；超支保留负值。以分为单位四舍五入。普通日均支出仍按完整支出计算。
- 明细预算「⋯」→“分类预算与显示设置”：每个分类的预算金额、已用与“计入明细”开关放在一起。开关即时保存，页面上方实时展示明细预算效果；编辑金额后需点“保存预算”，取消金额编辑不撤销显示开关。一级关闭时子分类全部排除，重新开启时保留子分类选择。名称通过预览标题旁铅笔修改。全部显示默认“本月预算”，部分排除默认“所选分类预算”；自定义名称优先。问号气泡显示包含/排除清单。偏好保存在本机 SQLite，适用于所有月份，不修改交易、同步操作或完整预算。开关使用 React Native Switch，iOS 底层为系统 UISwitch。
- 排除一级分类扣除该一级分配额，排除二级分类扣除其二级分配额，父子不会重复扣减。尚未分配到分类的额度保留在总预算或上级额度中；未设置分类额度时仅排除该分类支出。全部分类关闭时显示额度与已用均为零；未设置总预算仍显示“未设置”。退款使用原分类净抵扣。
- 统计卡片「⋯」→“统计口径”保存本机偏好。关闭时为“本月支出”；开启时为“本月流出”，金额下标注“含还款本金”。收入不受开关影响；结余同步采用当前口径，气泡解释它与净资产的区别。
- 统计日均使用所选完整区间的天数，气泡解释与明细日均的区别。保留上期比较、分类占比、分类展开和收支日历。
- 还款本金和本人账户间转账不占用预算。统计使用投影副本，不修改交易、账户、净资产或同步队列。
- “我的”采用头像区域和分组设置列表。外观页保留系统白、暖白、深色及系统主题选择和保存功能。

## 月份弹窗与统计时间选择

按后续要求，明细、统计和预算的月份入口统一使用紧凑自定义弹窗：年份左右切换、12 个月网格、当前月份提示、已选月份高亮、一键回到本月。点选立即生效；关闭、遮罩或 Web Escape 均不改变月份。页面保留居中年月和两侧圆形上月/下月按钮，支持跨年。

统计采用“周 / 月 / 年 / 全部 / 范围”分段控件；iOS 沿用原生分段控件，Web 使用灰色圆角轨道和白色选中块。周和年支持前后切换及直接选择；自定义范围通过气泡设置起止日期并校验。原有日期/时间入口保留系统控件。

新月份弹窗不依赖原有本地年月滚轮模块。iOS JavaScript/Hermes bundle 已导出成功。Windows 环境无法运行 iOS 模拟器；原生分段控件、VoiceOver 和真机触摸效果仍需在 iPhone 上验收。

## 固定支出演示

运行 `node scripts/preview.cjs --demo`，默认打开端口 4175，构建目录为 `tmp/budget-demo-web`。只有该构建启用示例标识，使用独立的 `budget-preview-demo.db`，首次打开写入示例数据，之后保留用户操作；普通构建继续使用原账本。示例模式不启动自动同步。

当前月完整预算 ¥10,000：固定支出预算 ¥6,000（房租 ¥4,500、水电燃气 ¥1,000、通讯订阅 ¥500），日常预算 ¥4,000（三餐 ¥2,500、生活用品 ¥1,000、日常交通 ¥500）。固定支出实际 ¥5,000，日常实际 ¥1,800，另有工资收入 ¥15,000。

关闭固定支出时，明细预算总额/已用/剩余从 ¥10,000 / ¥6,800 / ¥3,200 变为 ¥4,000 / ¥1,800 / ¥2,200，完整预算、明细与统计保持原金额。`scripts/smoke-budget-demo.cjs` 在隔离浏览器中验证这些变化、父子开关、金额编辑校验、取消与保存、名称和开关刷新后保持及 375px 布局。截图为 `budget-demo-*.png`。

## 分类环形图、日历与筛选反馈

分类图采用加厚环形、中心净额、环外分类名称与百分比，同色引导线沿环外排列。超过六个正值分类时，图上将较小项合并成“其他”，列表仍保留完整分类。零/负值不绘制扇区，但保留净额与记录。图表、图标和占比条使用一致颜色，重复分类颜色在图内区分。

分类卡片顶部收纳“环比金额/比例/隐藏”和“一级/二级分类及筛选”。列表增加笔数；展开一级分类可查看子分类金额、笔数和占本类比例。笔数包含影响当前收支的退款，子分类占比按其父分类下正值金额之和计算。收入/支出切换同步更新图表和列表。

统计顶部“显示设置”提供原生 Switch 控制收支日历，默认开启，只在月范围显示，关闭后收起整张卡片，刷新后保持。明细交易筛选明确显示“当前：全部类型”或具体选中类型；仅在已有类型筛选时出现“重置类型筛选”，重置不清空关键词和月份。

`scripts/smoke-statistics-display.cjs` 对示例预览验收日历显示/隐藏/重载/月份条件、分类展开与环比方式、收入切换、空月份、375px 深浅主题，以及重置类型后保留关键词，无页面错误。截图为 `stats-donut-*.png` 和 `stats-type-reset.png`。
