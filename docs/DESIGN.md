# 两个人的账本 — 暖白界面规范

本规范记录当前 Expo / React Native 实现，面向日常记账操作。暖色背景配合接近白色的卡片，避免资产页突然出现冷蓝色区域。金额靠字重和对齐形成层级，不靠额外装饰。主操作使用棕色强调色，收入和支出保留语义颜色。系统字体随平台和用户文字大小缩放。控件以清晰、可触达为先，常用入口不依赖悬停。经典和深色使用 `useTheme` 的各自取值，不混入暖白的颜色。

## Colors

来源：`src/components/ui.tsx` 的 `useTheme`。下表只记录暖白浅色。

| 语义 | 值 | 使用 |

| bg | #F5F1EA | 页面底色 |
| card | #FFFDFA | 表单和列表表面 |
| text | #1C1C1E | 正文与金额 |
| muted | #67676F | 次要标签 |

## Typography

使用系统字体，无额外字体下载。正文 15–16，说明 12–13，列表金额 17，账户卡片标题 18，页面标题 34。金额使用现有 `formatMoney`，不自行计算小数。`Txt` 的字重为 400/600。明细汇总数字基准 38、字距 -1，货币符号和小数降低字号；特别长的金额按长度适配，保留系统文字缩放与换行空间。

## Spacing and shapes

输入框圆角 13、最小高度 48、横向内边距 14。键盘按键圆角 14、最小高度 44。转账账户卡片圆角 22、内边距 12，点按后打开账户选择面板。明细行纵向内边距 10，主汇总卡片内边距 18，以收支、预算两页替代多组竖向堆叠；辅助标签与金额优先同行，窄屏可换行。相邻字段用 8–12 间隔，财务数字字段可并排。不要为塞入一屏缩小关键文字；375×667 可滚动，390×844 分摊主要表单可一屏显示。

## Components and states

- 账户卡片：默认 card/line，选中 soft/accent；实际账户名称直接显示。隐私目标始终使用“我的/对方的隐私账户”，不给真实账户资料占位。
- 多选导出：checkbox 同时有可访问性 checked 状态、图标和文字。0 项禁用导出，进行中禁用重复点击并显示“正在导出…”。
- 记账设置：账户选择同一行右侧直接显示“关联行程”，选中后显示行程名称；选择或创建后关闭弹层。齿轮打开底部“更多设置”，包含“不计入预算”“不计入收支”两个 checkbox；主界面显示已启用排除选项的简短摘要。低频操作折叠在“其他操作”中，窄屏可滚动。
- 资产账户列表隐藏租赁预付及关联押金账户（含已归档），资产汇总仍包含这些余额，租房计划继续管理记录。
- 可选日期的“清除日期”仅按钮本身可点击，所在行空白处不触发清除。
- 时间：金额卡下方以时钟图标和时间作为入口；iOS 使用系统 compact 时间选择器，网页使用浏览器时间控件。
- 分类：记账页遵循分类管理保存的顺序，不再按最近使用自动重排；常用模板仍保留。
- 常用：从“添加常用”选择分类后进入模板保存；说明保存分类、账户、金额和备注。
- 筛选：右上角成员选择显示当前范围；统一使用 chevron.down 图标，不用 Unicode 箭头或备用星星。
- 分摊：总额、期数、普通期金额、末期金额来自同一个整数分摊函数；日期明细按需展开。不存在的日期取月末，下月恢复原日。
- 错误、空列表、无账户：文字说明下一步；隐私未配置收款账户时显示待入账，不把未入账伪装成成功到账。

## Motion and accessibility

采用 Emil `animate-expo` 的高频操作门槛：键盘、分类选择、统计开关不新增动画；点按立即反馈。账户选择弹层只使用短淡入，系统减少动态效果时关闭该弹层动画，导航改为淡入。保留系统字体缩放；触控区域至少 44 pt。iPhone release build 的手势流畅性、VoiceOver 和大字体适配未由网页测试证明。

## 分类设置与简短说明（2026-10-31）

分类区用设置图标进入分类设置，新增/修改/排序集中在此。齿轮采用连续齿廓，不以放射线代替。排序独立打开列表：一级分类与同组二级分类分别调整，完成保存、取消放弃；iOS 采用系统 UITableView reorder control，Web 使用拖拽把手及方向键。普通明细不展示付款人和记录人，完整信息仅在核对/详情使用。预算开关规则放在问号内，预算范围说明不罗列全部分类。

预算页不再显示重复的明细效果卡；分类名称与金额使用紧凑双行结构，长金额允许自然换行，展开触控区域保留 44 pt 以上，编辑模式保留足够的输入高度。

## 分类环图配色与引导线（2026-10-31）

统计使用独立的分类色板：蓝 `#4D83F3`、珊瑚红 `#EF6C78`、青绿 `#20AB9D`、紫 `#9670DD`、橙 `#F39B45`、绿 `#55A64E`；合并的“其他”用灰 `#8B95A5`。不沿用分类管理中的土黄或相近色；图中每个可见分类、引导线、列表图标和进度条共用颜色映射。一级、二级分别分配基础颜色，可见分类发生颜色重复时重新分配空闲颜色，不修改保存的分类资料。

标签按左右两侧避让，连线使用短径向段、斜向段和水平末端。圆环根据标签空间选择起始角度，使拥挤的小分类优先落在侧面；金额和扇区占比保持原值，不人为放大小扇区。窄屏缩短左右留白并适配中心金额字号，名称去掉分隔符后显示，完整名称仍保留在列表和可访问性描述中。

参考：[Carbon 分类色板](https://www.carbondesignsystem.com/building-blocks/data-visualization/color-palettes)、[ECharts 外部标签避让](https://echarts.apache.org/handbook/en/how-to/chart-types/pie/doughnut/)。实现使用现有 React Native SVG，不新增图表依赖。`tests/donutPresentation.test.ts` 覆盖截图比例、多极小分类、七种图表宽度的标签间距及连线相交/穿环检查；`scripts/smoke-donut-colors.cjs` 在独立浏览器中验证 320/375/390px、暖白与深色。截图位于 `docs/acceptance/stats-donut-colors-390.png`；网页验证不代表 iPhone 真机验收。
