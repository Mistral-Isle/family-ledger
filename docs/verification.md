先导出 `tmp/final-build`；安装可用的 Playwright 或将 `PLAYWRIGHT_MODULE` 指向现有模块目录，脚本使用本机 Edge 的无头模式。

node scripts/smoke-reports.cjs tmp/final-build
node scripts/smoke-web.cjs tmp/final-build
