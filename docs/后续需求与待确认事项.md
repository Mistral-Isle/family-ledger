| 优先级／阶段 | 待开发内容 | 验收要点 |

| 阶段 2 | 周／月／年／全部／自定义范围统计、分类层级与环比、月预算、收支日历 | 转账不计收支；预算和图表与明细口径一致 |
| 阶段 2 | CSV 与 Excel 导出及系统分享 | 明细、分类、成员、账户余额、贷款进度五张表（贷款未上线时说明状态）；Excel/WPS 可打开；不泄漏私有数据 |

| 阶段 3 | 家庭与小金库之间转账 | 家庭侧仅保留约定的金额外壳；双边余额正确；先确认展示口径 |
| 阶段 4 | 简易贷款、免息期、结清计划、还款、一次结清、校准本金、利息／手续费及本地提醒 | 先通过规划中的贷款计算用例，再实现界面；负债正确计入净资产 |

| 阶段 5 | WebDAV 加密日志、HLC 合并、前台自动同步、错误状态、扫码配对、恢复码、手动同步包 | 两设备离线、乱序、重复、并发修改测试；存储端只有密文；私有数据不进入日志 |
| 阶段 6 | 未签名 IPA 构建流程、SideStore 安装、升级保留数据、两台手机配对与恢复 | 备份完成后才进入真实数据使用；两台 iPhone 实测通过 |

| 事项 | 规划中的建议／默认 | 需要确认的信息 |

| 租房信息 | 押金作为资产，预付费用按月分摊 | 月租、起租／上次交租日、押金、付款账户、已经付到哪个月 |

| 日常模式 | 分类 + 可选账户、金额、备注预设 | 是否保留现有预设方式，还是只展示常用分类 |
