- 坚果云 WebDAV；账号与应用密码只在 App 设置输入。
- 家庭与小金库互转采用方向＋金额外壳，不展示私有账户和备注。
- 超额退款转收入；右滑退款、左滑删除、点按编辑、长按多选；底部四则键盘。
- 范围统计、预算、日历、家庭导出、成员筛选／占比、账户归属、分类删除与恢复。

## 当前需要外部条件的验收

- GitHub remote 或 macOS：运行已准备的 iOS workflow，取得真实编译反馈与未签名 IPA。
- 两台 iPhone：侧载、设备验证、后台锁定、扫码配对、通知、系统分享／文件选择、触摸与深浅色。
- App 内填写坚果云凭据：验证 WebDAV 服务实际行为、跨设备收敛、密文文件和恢复码重建。不在聊天或仓库保存密码。
- 用户现用 App 的 10 月对照数据与 Excel/WPS：核验真实统计及 Office 打开效果。合成数据与 SheetJS 读回已通过，不能替代这一验收。
- 用户先前提到的“小问题”尚无具体复现路径，不视为已经修好。
