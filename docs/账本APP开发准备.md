## 💻 一、Windows 电脑端准备清单

**阶段 1：搭建 AI 开发环境（写代码用）**

- [ ] **安装 Node.js**：下载并安装官网 **LTS（长期支持版）**，安装后在终端运行 `node -v` 确认成功。
- [ ] **确认 Git 环境**：确保终端里 `git` 命令可用。
- [ ] **配置 AI 编码工具**：打开 **VS Code**（安装 **Cline** 或 **Roo Code** 插件并配置好大模型 API），或者直接安装 **Cursor**。
- [ ] **【新增】注册 GitHub 并建一个私有仓库**：例如 `family-ledger`。既做版本管理，也是第 3 步用 GitHub Actions 打包的前提。
- [ ] **【修改】Expo 账号（可选）**：用 Expo Go 预览不需要登录，本方案也不用 EAS 云打包，所以可以先不注册。

**阶段 2：配置首次自签环境（仅第 1 次装 SideStore 时用一次）**

- [ ] **安装非商店版 iTunes**：去苹果官网下载安装 Windows 64 位独立安装包（如果电脑里装过微软商店版的 iTunes，需先卸载，否则底层驱动无法识别）。
- [ ] **下载安装 iloader**：去 GitHub 下载 [`iloader-windows-x64.msi`](https://github.com/nab138/iloader/releases) 并安装。
- [ ] **准备一根数据线**：确保能连接电脑与 iPhone 进行数据传输。

**阶段 3【新增】：家庭同步准备（开发到"同步"阶段前完成即可）**

- [ ] **注册坚果云**：[https://www.jianguoyun.com](https://www.jianguoyun.com/)，免费版即可。
- [ ] **生成应用密码**：网页端「账户信息 → 安全选项 → 第三方应用管理」→ 添加应用 → 生成密码。App 里填的是这个密码，不是登录密码。服务器地址：`https://dav.jianguoyun.com/dav/`。
- [ ] **（可选）电脑装坚果云客户端**：同步 App 用的那个文件夹，电脑上就自动多一份（加密的）备份。

## 📱 二、你的 iPhone 准备清单

- [ ] **下载 Expo Go**：用主力账号在 App Store 搜索并安装 **Expo Go**（开发阶段扫码实时预览界面用）。
- [ ] **下载 LocalDevVPN**：切换外区 Apple ID，在 App Store 搜索并安装 **LocalDevVPN**（打开后点一次 `Connect` 允许添加 VPN 配置）。
- [ ] **准备签名用 Apple ID**：准备一个用于给 SideStore 签名的免费 Apple ID（可以直接用现有的，也可以单独注册一个新号专门用来签名，注意开启双重认证）。**以后一直用这同一个 Apple ID 签名。**

## 👫 三、【新增】另一半的 iPhone 准备清单

她不参与开发，所以不需要 Expo Go，只需要能装上做好的 App：

- [ ] **准备她的签名用 Apple ID**（开启双重认证）。建议用她自己的，不和你共用。
- [ ] **下载 LocalDevVPN**：同样需要外区 Apple ID 才能下载。
- [ ] **装 SideStore**：按第四节第 2 步，用你的电脑 + 数据线给她的手机做一遍（只需一次）。
- [ ] **设好每天凌晨自动续签的快捷指令**（同第 2 步第 4 条）。

## 🚀 四、实战推进顺序（Step-by-Step）

**第 1 步：跑通第一个测试页面（预计 15 分钟）**

- [ ] **1. 初始化项目**：在电脑新建文件夹，终端运行 `npx create-expo-app@latest my-ios-app` 创建项目。
- [ ] **2. 启动预览服务**：进入目录运行 `npx expo start`（如果电脑开着 Clash Verge 的 TUN 模式导致手机扫不出局域网，可改用 `npx expo start --tunnel`；**首次会提示安装 `@expo/ngrok`，速度比局域网慢，能用局域网就用局域网**）。
- [ ] **3. 手机扫码体验**：确保手机和电脑在同一 Wi-Fi 下，用 iPhone 相机或 **Expo Go** 扫码，看到屏幕出现默认欢迎页即代表开发链路打通。
- [ ] **4. 【新增】推到 GitHub**：`git init` → 关联私有仓库 → 第一次 push。
- [ ] **5. 召唤 Agent 写代码**：把《双人家庭记账 App · 需求与开发规划》交给 Agent，按里面的阶段 0 → 6 推进。**提醒 Agent：只用 Expo Go 能运行的库**（规划书的选型已满足）。

**第 2 步：首次部署 SideStore 独立自签（预计 15 分钟）** *(可以起步时先做，也可以等 App 写好准备装到桌面时再做；另一半的手机也要做一遍)*

- [ ] **1. 插线注入**：手机开启 `LocalDevVPN`，用数据线连电脑并点击"信任此电脑"。打开电脑上的 **iloader**，登录 Apple ID 并点击安装 `SideStore (Stable)`。
- [ ] **2. 开启权限**：拔掉数据线 → 去手机 `设置 - 通用 - VPN与设备管理` **信任证书** → 去 `设置 - 隐私与安全性` 底部开启 **开发者模式** 并重启手机。
- [ ] **3. 自身续签激活**：重启后连上 `LocalDevVPN`，打开桌面上的 **SideStore** 登录同一个 Apple ID，在 `My Apps` 里点一下 SideStore 旁边的 `7 DAYS` 完成首次自身刷新。
- [ ] **4. 配置凌晨自动续签**：在手机"快捷指令 - 自动化"里设好每天凌晨 03:00 自动执行：`连接 LocalDevVPN` ➔ `等待 3 秒` ➔ `Refresh All Apps` ➔ `断开 LocalDevVPN`（或切回你的代理软件）。

**第 3 步【修改】：用 GitHub Actions 打包 `.ipa` 并安装到桌面（开发完成后）**

> 原方案的 `eas build -p ios` 在打真机包时要求 Apple 证书，只有付费开发者账号才能生成，所以换成下面的做法：在 GitHub 的 Mac 机器上编译一个**不签名**的 ipa，再交给 SideStore 用你的免费 Apple ID 签名。

- [ ] **1. 定好 Bundle ID**：在 `app.json` 里设置 `ios.bundleIdentifier`（例如 `com.<你的名字>.familyledger`），**之后不要再改**（改了等于新 App，数据不会跟过去，还会占用免费账号的 App ID 配额）。
- [ ] **2. 让 Agent 写打包流程**：在项目里新建 `.github/workflows/ios-unsigned.yml`，大致步骤： `macos-latest` 机器 → 安装依赖 → `npx expo prebuild -p ios --clean` → `xcodebuild archive ... CODE_SIGNING_ALLOWED=NO` → 把 `.app` 放进 `Payload/` 文件夹压缩成 zip，改名 `.ipa` → 作为构建产物上传。
- [ ] **3. 触发打包**：push 代码后，在 GitHub 仓库的 **Actions** 页面手动运行这个流程，等 15–25 分钟。
- [ ] **4. 下载并安装**：在这次运行的页面下载产物（zip 里是 `.ipa`）→ 用微信文件传输助手 / AirDrop 发到手机 → 存到"文件" App → 打开 **SideStore** 点 `+` 选这个 ipa 安装。
- [ ] **5. 额度**：私有仓库每月有 $12 免费额度，macOS 机器约 $0.062/分钟，大约够 190 分钟，也就是每月 8–10 次打包；公开仓库不计费。平时开发用 Expo Go 预览，只在需要装到桌面时才打包。
- [ ] **6. 升级安装前先备份**：同一个 Bundle ID 覆盖安装一般会保留数据，但保险起见，每次装新版前先在 App 里导出一次备份。

**第 4 步【新增】：装到另一半手机并配对（同步功能完成后）**

- [ ] **1.** 把同一个 `.ipa` 发给她，她用自己手机上的 SideStore 安装。
- [ ] **2.** 你在 App 里创建家庭账本（填坚果云账号 + 应用密码）→ 显示配对二维码。
- [ ] **3.** 她打开 App 选"加入家庭账本"→ 当面扫码 → 自动下载已有数据，完成。
- [ ] **4.** 两人各自抄下设置页里的**家庭恢复码**，重装时用。

## ⚠️ 五、【新增】注意事项

- **免费 Apple ID 的限制**：同时最多 3 个侧载 App 处于激活状态（SideStore 自己占 1 个）；每 7 天最多注册 10 个 App ID；签名 7 天过期（靠每日自动续签解决，过期也不会丢数据，续签后就能打开）。
- **删除 App = 本地数据全丢**：不要随手删除重装；正式使用前，App 的"导出备份"功能要先做好。开启家庭同步后，对方手机和坚果云也相当于一份备份（小金库除外，它只在本机）。
- **VPN 只能开一个**：LocalDevVPN 和 Clash 会互相顶掉，所以快捷指令最后一步要切回代理。App 的同步走普通网络，不受影响。
- **Expo Go 里 Face ID 不可用**：小金库解锁在 Expo Go 里会变成输入设备密码，这是正常的；装成正式 App 后才有 Face ID。
- **免费账号不支持 iCloud 和远程推送**：所以同步用坚果云，提醒用本地通知（还款、交租提醒都没问题）。
