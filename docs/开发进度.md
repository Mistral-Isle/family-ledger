## 已完成

- Expo / React Native / TypeScript 工程、四个 Tab、SQLite 本地持久化、版本迁移与操作日志。
- 支出、收入、转账，账户与分类基础管理，搜索、月度统计、常用记账预设。
- 点按流水直接编辑；右滑退款、左滑删除；长按进入多选批量删除。
- 退款关联原支出，支持分次退款、编辑与删除；原支出额度内抵减支出，超额记为收入。
- 安装并应用 apple-design skill，调整字体、分组背景、图标、按钮反馈和滑动动画。
- 底部固定四则运算键盘：移除等号和双零，支持单格退格、实时结果、保存时自动计算。
